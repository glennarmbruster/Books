# Goobie's Survival Guide

[Download the illustrated book for Apple Books](./Field-and-Home.epub?raw=true). On iPad or iPhone, share the downloaded file to Books. The chapter contents link to individual guides, and the illustrations are included for offline reading.

Open [the web reader](./index.html) from a local copy or serve this folder as a static site to use guide search, personal notes and the workshop log. Tap any step illustration for a larger view.

The back-of-book Food Safety Quick Reference appendix includes refrigeration decisions, storage times, freeze-dried product examples, and cat food and treats.
