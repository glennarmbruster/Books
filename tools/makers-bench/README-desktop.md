# The Maker’s Bench · Desktop
This folder contains the complete standalone book, with the project guides, artwork, fonts, design studio, workshop and export engines.

## Publish with GitHub Desktop on Windows or Mac
1. Unzip the archive. Copy its contents into your separate repository, with index.html at the repository root. Keep the images and vendor folders intact.
2. In GitHub Desktop, commit the files and push to GitHub.
3. On the repository website, choose Settings → Pages → Deploy from a branch → main → / (root), then Save. Open the published Pages address in your browser.

Open the book online once and wait for **Ready offline** at the bottom. Reopen that same address when offline. For local use without publishing, serve the folder on localhost (for example, run `python3 -m http.server 8000` here and open http://localhost:8000/). Opening index.html as a disk file does not support the offline installer or all export formats.

To update this separate repository, unpack the next ZIP over the previous edition, commit and push again. Keep the same site address to retain this browser’s saved projects. To move a design between devices or editions, download its project file in My workshop and open it in the other workshop.
